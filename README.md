# cardano-note

Cardano まわりの**公開動画**（Midnight・Input Output・Charles Hoskinson のチャンネルなど）を、1 本ずつ読み解いたノート。

**公開ページ:** <https://shiodome47.github.io/cardano-note/>

1 本の動画につき 3 ページ —— 日本語のまとめ（英語版も同じページに）、日本語全文、英語全文（原文）—— と、3 つを 1 枚にまとめた `standalone.html` がある。

## 方針

- **公開されている動画だけを扱う。**発言者は実名のまま書く
- **動画で語られたこと、画面に映っていただけのこと、こちらで足した説明を、印で区別する**
- **各回は、その時点で何が語られたかの記録。**あとで状況が変わっても本文は書き換えず、「動画公開後の結果」として印付きで足す
- **予測・時期・数字は、言われたとおりの確度で書く**

姉妹リポジトリ [`2026RealFi`](https://github.com/shiodome47/2026RealFi) は RealFi のコミュニティコールの記録で、成果物の形式は同じ。あちらは匿名化の規律があるクローズドなコールを扱い、こちらは公開動画だけを扱う。

## 回を足すには

動画の URL と字幕ファイル（`.srt` または `.txt`）を渡す。作り方は `CLAUDE.md` にすべて書いてある。

```
python3 tools/check.py                   # 生成物の検証（コミット前に必ず）
python3 tools/build_standalone.py        # 1 枚版の再生成
```

## ディレクトリ

```
├── CLAUDE.md          作り方と完成条件
├── episodes/          原本（字幕ファイルと meta.yml。無加工）
├── shared/            用語集・話者メモ・保留の問い・チャンネルの定義
├── tools/             検証と 1 枚版の生成
└── docs/              公開する成果物（GitHub Pages のルート）
```
